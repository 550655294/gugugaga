## 一、角色设定

### 🐧 企鹅妹妹 战斗形态

沿用普通规范文档的完整角色设定（头身比 1:2、呆毛、腮红、翠绿圆眼、黑白连体睡衣等），在此基础上叠加战斗特化：

- **战斗表情**：奶凶为主，凶不过三秒即崩为软萌
- **战斗姿态**：双蹼足微蹲/前倾/小拳拳举胸前（鳍翅卷成团），呆毛绷直
- **受伤反应**：被击中后原地转圈 + 豆豆眼 + 呆毛软塌 → 1秒后爬起来继续
- **胜利反应**：呆毛弹跳 + 半月弯眼 + 鳍翅举天 + 原地跳三下

### 👾 对手设定

| 类型 | 示例 | 特点 |
|------|------|------|
| 家电拟人 | 吹风机、吸尘器、扫地机器人 | 没有脸但「有情绪」，通过动作/震动/声音表达 |
| 自然元素 | 风、雨滴、纸团 | 无形或轻盈，靠环境互动 |
| 日常物品 | 枕头、袜子、拖鞋 | 静态变动态，突然"活过来" |
| 萌系角色 | 毛绒玩具、橡皮鸭 | 有眼有嘴，风格统一为Q版 |

## 二、战斗规则

### ⚔️ 核心原则

1. **萌系战斗**：可爱 > 暴力，动作夸张但无害，强调表情和肢体搞笑
2. **三秒反转**：每次交锋的"紧张感"维持不超过3秒即转为搞笑/意外
3. **无实质伤害**：所有攻击都是棉花级别的，被击中后瞬间恢复

### 🎬 战斗动作库（v2.0 武功系统）

> 🔥 **核心要求**：每场战斗至少使用 **4个命名招式**（场景一2个+场景二2个），招式必须包含**起手式→出招→特效→收招**完整动作链。招式名称在提示词中以 `【招式名】` 标注。

| 对手类型 | 招式风格 | 特效色系 |
|----------|----------|----------|

| 日常物品 | 利用物品物理特性形成"招式"（如枕头=羽毛散华、弹力球=彩虹弹幕） | 物品本身颜色 |
| 自然元素 | 利用物理规律形成"招式"（如风=风刃、纸团=纸片手里剑） | 白色/透明+环境光 |

> ⚠️ 招式命名要求：中文四字为主（如"棉花乱打""旋风企鹅转"），萌系感+武打感兼备。招式名必须在提示词中以 `【招式名】` 格式标注。

### 🚫 战斗禁令

- ❌ 血腥、断肢、任何红色液体
- ❌ 真实武器（刀/枪/棍棒/砖头）
- ❌ 颈椎/头部致命伤害
- ❌ 火焰/高温灼烧
- ❌ 电击
- ❌ 坠落重伤
- ❌ 任何角色进医院/昏迷/死亡

## 🔥 特效系统（v2.0 新增）

> **核心要求**：每场战斗至少包含 **5种以上特效类型**，特效必须与招式一一对应。禁止"只有碰撞没有特效"的苍白战斗。

### 特效层级（从低到高）

#### L1·基础特效（每回合必含至少1种）

| 特效名 | 触发场景 | 视觉描述 |
|--------|----------|----------|
| **冲击波** | 任何招式命中瞬间 | 命中点爆开环形波纹，粉色/金色/淡蓝色同心圆向外扩散 |
| **速度线** | 快速移动/冲刺/闪避时 | 角色身后拖出平行白色速度线，移动越快线条越密集 |
| **光粒子** | 能量类招式/气场释放 | 对应招式色系的小光点从角色身体/道具向四周飘散 |
| **慢镜头定格** | 关键命中瞬间/搞笑反转 | 画面0.5秒内从正常速度降至25%→暂停→恢复 |

#### L2·进阶特效（每场景至少1种）

| 特效名 | 触发场景 | 视觉描述 |
|--------|----------|----------|
| **残影/分身** | 高速闪避/瞬步/影分身 | 半透明金色/角色本色残影拖在身后，滞后0.2秒消失 |
| **气场/爆气** | 蓄力/愤怒/认真模式 | 角色身体周围浮现对应色系的气焰（咕嘎=粉色，菲比=淡蓝），头发/呆毛被气劲吹起 |
| **震屏** | 奥义命中/大型冲击 | 画面轻微上下抖动，持续时间0.3秒 |
| **地面裂痕** | 重击落地/大型招式余波 | 地面出现萌系星星/羽毛形状的浅裂纹，2秒后消失（非真实破坏） |
| **武器/道具拖尾** | 权杖挥动/弹力球飞行/纸团飘浮 | 道具运动轨迹上留下对应色系的光轨，0.5秒消散 |

#### L3·终极特效（每集至少1种）

| 特效名 | 触发场景 | 视觉描述 |
|--------|----------|----------|
| **黑白闪** | 奥义发动瞬间 | 画面瞬间变为黑白负片+单色高光，持续0.2秒后恢复彩色 |
| **羽毛/星星风暴** | 大型招式碰撞 | 画面被白色羽毛/金色星星/彩色光点填满，像烟火绽放 |
| **镜头推拉** | 对峙结束→爆发瞬间 | 镜头从全景急速推近到面部特写→再急速拉远到全景，一秒内完成 |
| **能量对冲** | 两股招式能量互撞 | 粉色和蓝色（或其他色系）两股能量在画面中央对撞，形成半球形能量罩 |

### 特效色系映射

| 角色/元素 | 主色 | 辅色 | 粒子形状 |
|-----------|------|------|----------|
| 咕嘎 | 粉色 #FF99CC | 金色 #FFD700 | 小圆点 + 羽毛 |
| 菲比/圣光 | 淡蓝 #99CCFF | 白色 #FFFFFF | 十字星 + 光点 |
| 弹力球 | 彩虹七色 | 白色高光 | 圆形光斑 |
| 纸团 | 纯白 | 米白 | 不规则飘絮 |
| 吹风机/风 | 薄荷绿 | 白色气旋 | 风纹螺旋 |
| 扫地机器人 | 金属银 | 蓝色指示灯 | 环形光波 |
| 枕头/羽毛 | 纯白 | 暖米色 | 羽毛 + 光点 |

### 特效节奏规则

- **普通回合**（基础招式对撞）：L1特效 ×2~3种
- **关键回合**（命名招式命中）：L1 ×3 + L2 ×1~2种
- **奥义回合**：L1全开 + L2全开 + L3 ×1~2种
- **搞笑反转**：特效突然中断或变成搞笑效果（如气场变成爱心气泡、冲击波变成棉花糖形状）
- 特效不可连续同一类型超过3秒，必须有变化

### 📍 场景一时长分配（12-15s范围内，v2.0 更新）

- 0-1.5s：快速建立环境（不超过2秒，禁止长铺垫）
- 1.5-3s：对峙/挑衅 + 咕嘎摆出第一个起手式
- 3-8s：**第一轮交锋**（至少2个命名招式 + 对应特效）
- 8-12s：**第二轮交锋**（招式升级 + 特效升级 + 搞笑意外）
- 12-15s：收尾定格（慢镜头 + 最紧张一帧/对峙僵持）

### 📍 场景二时长分配（12-15s范围内，v2.0 更新）

- 0-3s：紧接上一场景末帧 + **第三轮交锋爆发**（至少1个进阶招式 + L2特效）
- 3-8s：**第四/五轮交锋**（连招组合 + 多重特效层叠 + 搞笑反转）
- 8-12s：**高潮/奥义回合**（如使用奥义→L3特效全开；如搞笑收尾→特效崩塌成萌系效果）
- 12-15s：收尾定格（氛围回落 + 温馨余韵）

### 🎯 每段必须包含（v2.0 强化）

1. **至少2个命名招式**（以 `【招式名】` 标注在提示词中）
2. **1个慢镜头瞬间**（动作拖慢0.5秒的感觉，中文提示词写"慢镜头：..."）
3. **1个搞笑意外**（出招失败/对手不配合/自己绊倒/特效崩塌）
4. **至少2种表情变化**（从表情微动作库选用）
5. **至少3种特效类型**（从特效层级 L1~L3 中选取，必须包含至少1个 L2）
6. **招式必须完整**：起手式→出招→特效绽放→收招/后摇，不可只写"冲过去"

## 五、战斗安全铁律

### 🔧 身体部位安全（战斗模式）

> 战斗场景中允许合理的肢体碰撞动作（鳍翅拍打、呆毛戳、蹼足踢），但仍禁止以下过度工具化描述：

| 禁止项 | 原因 | 替代描述 |
|--------|------|----------|
| 呆毛勾取/拖拽/缠绕物体 | 呆毛是表情指针，不是工具 | "呆毛绷直像剑一样点向XX" |
| 呆毛像钩子/机械/开出小花 | 违反生物感 | "呆毛高高竖起，尖端微微发亮" |
| 嘴张成O形/伸长/无底洞 | 破坏萌感 | "嘴巴微张，露出惊讶的小粉舌" |
| 腮帮像气球 | 比例失衡 | "腮帮鼓得圆溜溜的" |
| 星星眼 | 过于夸张 | "翠绿圆眼闪烁高光" |
| 舌头像着火 | 危险暗示 | "辣得直吐小舌头" |

### 🏥 物理安全

- 被击飞的高度不超过 2 个企鹅身高
- 落地必须有软垫/棉花堆/沙发等缓冲
- 严禁坠楼/触电/溺水/窒息

## 八、抖音标题生成规范（v2.1 新增）

> 🎯 战斗分镜每集必须输出抖音标题。标题紧扣本集核心招式/特效/反转三大战斗钩子。

### 标题公式

```
[核心招式/特效钩子] + [情绪张力/搞笑反转] + [话题标签]
```

### 战斗三大钩子（每条标题至少命中2个）

| 钩子类型 | 说明 | 示例 |
|----------|------|------|
| 🥋 招式钩子 | 本集最亮眼的命名招式或连招 | "棉花拳vs圣光屏障""肉弹战车穿破纸团群" |
| ✨ 特效钩子 | 视觉冲击最强的特效瞬间 | "粉色vs淡蓝能量对冲""黑白闪爆开七彩星光" |
| 😂 反转钩子 | 搞笑意外/特效崩塌/傲娇认输 | "守护光环变爱心气泡""气劲变小花" |

### 标题风格分类

| 风格 | 公式 | 适用场景 |
|------|------|----------|
| 对决向 | X vs Y，结果Z | 双角色武打（如咕嘎 vs 菲比、企鹅流 vs 圣光流） |
| 反差向 | 本以为A，结果B | 特效崩塌/搞笑反转/奥义翻车 |
| 解说向 | X招式命中，Y反应令人心疼 | 招式观赏性强、慢镜头高光 |
| 短打款 | 画面词+emoji+话题 | 需快速抓住注意力 |

### 标签规范

| 必选标签 | 可选标签（按剧情选） |
|----------|---------------------|
| `#咕嘎` `#萌系战斗` | `#企鹅流武学` `#棉花拳` `#特效拉满` `#搞笑反转` `#萌系动画` `#对决` `#奶凶` |

- 总标签数 **3-5 个**
- `#咕嘎` 为每集必带品牌标签
- `#萌系战斗` 为战斗分镜必带标签（区分普通分镜的 `#萌系动画`）
- 禁用 `#嘎嘎` 标签

### 标题约束

| 规则 | 说明 |
|------|------|
| 长度 | 单条标题核心句 ≤30 字（不含标签） |
| Emoji | 1-3 个，战斗向优先用 ⚔️🥋✨🔥⚡️😂🧸💥 |
| 禁词 | 严禁标题中出现"嘎嘎"（连标签也不行） |
| 输出数量 | 每次给出 4-6 条备选，标注推荐款 + 1条短打款 |
| 位置 | 标题段落放在自检清单之后、文件末尾 |
| 格式 | `## 抖音标题（4-6条备选）` 作为二级标题 |

### 输出格式模板

```
## 抖音标题（4-6条备选）

**推荐款：** [核心句 ≤30字，含招式/特效/反转钩子]

**备选1：** [不同角度的标题]
**备选2：** [不同角度的标题]
**备选3：** [不同角度的标题]
**备选4：** [不同角度的标题]
**短打款：** [emoji+核心句] #咕嘎 #萌系战斗 [其他标签]
```

### 示例（来自 战斗004_权杖对决）

```
**推荐款：** 企鹅流武学vs圣光流杖术，结果守护光环变成了爱心🩷⚔️

**备选1：** 粉色气劲对轰淡蓝圣光，打着打着滚进靠垫堆了😂🐧
```
