## 三、john 的技术教程精华

### 3.1 姿势控制三件套

john 多次分享的姿态控制工作流：

```
① 参考图（目标服装/场景）
② 手绘火柴人线稿（目标姿势/动作）
③ 人脸模板（目标面部特征）
→ 三者同时上传 Seedance「全能参考」
→ Prompt 中明确 @参考图1 @参考图2 @参考图3 的用途
```

### 3.2 火柴人画法（控制成本最低）

```
头部：圆圈
躯干：一条竖线
四肢：四条线，关节处画小圈
→ 极简即可，Seedance 能理解

关键：火柴人的比例和角度决定最终姿势，
不需要画细节，只需要骨架方向。
```
