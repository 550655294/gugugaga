### 🛡️ 内容安全铁律（平台审核红线）⚠️

> ⚠️ 以下场景/元素已被实际审核拦截，**绝对禁止出现**。违者100%不过审。

| 禁止场景 | 原因 | 替代方案 |
|----------|------|----------|
| ❌ 床上/被窝/卧室睡觉 | 床戏触发"低俗"审核（即梦实测：脚本004数羊失眠已因卧室床景被拒） | ✅ 困了趴桌上/靠沙发打盹，不躺床 |
| ❌ 浴室/洗澡/浴缸 | 浴室场景触发内容安全过滤 | ✅ 洗手台洗手/照镜子，不涉及洗浴 |

| ❌ 睡衣/浴袍/毛巾 | 着装暗示私密空间 | ✅ 始终穿黑白企鹅连体睡衣（外出场景可加配饰） |

> **核心原则**：企鹅妹妹活动范围在公共/半公共空间（客厅、厨房、商店、户外等），不涉及卧室私密场景。即使剧情需要"困/累"，也通过趴桌、靠沙发、打哈欠等方式表现，**绝不上床**。

## 三、互动模式系统（A / C 二选一）

> ⚠️ B模式（第二角色出场）已暂时停用。当前仅 A、C 两种模式。

### 模式说明

| 模式 | 代号 | 占比目标 | 描述 |
|------|------|----------|------|
| 我的大手入镜 | A | ~60% | 人类的手从画面边缘自然伸入与妹妹互动（不露脸） |
| 纯独角戏 | C | ~40% | 妹妹独处卖萌，无其他角色 |

### 模式A：「我的大手」入镜互动

- **入镜方式：** 一只手从画面下方/右侧/左侧自然伸入（不露脸，只露手和前臂）
- **手型描述：** 温暖的人类大手，手指修长，动作轻柔
- **常见互动场景：**
  - 递东西：递食物、递水杯、递玩具、递遥控器
  - 帮忙：帮她擦脸、帮她摘东西、扶她起来、轻戳她肚皮
  - 互动游戏：挠痒痒、剪刀石头布、击掌、摸头
  - 制造冲突：拿走她的零食、关掉电视、把东西放到高处
- **妹妹的反应：** 眼睛追着手的动作，呆毛随情绪变化，发出对应的咕嘎拟声词
- **手的"台词"：** 手本身不说话，但动作传达意思；可配合画面字幕（如"不行哦""给你"）增强叙事

### 智能均衡轮换规则 ⚠️

`generate_scripts.py` 自动统计已有脚本的模式使用量，生成时优先补缺口：
- 按 A/C 实际占比与目标的偏差，优先选择缺口最大的模式

> ⚠️ **v4.6起**：每次随机选择「单长场景」或「双短场景」格式。两种格式输出顺序不同（见 §十一）。

### 单长场景（24s连续）输出顺序：
```
1. 📋 生成操作卡                  ← 生成24s视频前的全部准备清单
2. 🎯 即梦生成参数                ← 模型/比例/积分等（时长标注 24s×1）
3. 中文提示词（Seedance 2.0）     ← 格式A + 格式B，见§六
```

### 双短场景（12s+12s双段）输出顺序：
```
1. 📋 生成操作卡                  ← 一张卡覆盖双场景全部素材
2. 🎯 即梦生成参数                ← 时长标注 12s×2
3. 中文提示词（双短场景）         ← 仅输出【场景一】【场景二】分段（不输出格式B）
```

### 🚫 绝对禁止输出的内容：
- ❌ 场景1/场景2 分割（v4.4废除）
- ❌ 第一场景操作卡 / 第二场景操作卡（合并为单张操作卡）
- ❌ 8段表格（段/秒/拟声词/语调/音效）
- ❌ 一句话梗概
- ❌ "素材需求清单"独立章节（操作卡已覆盖全部素材需求）
- ❌ "参考第N集"标记
- ❌ **文件第一行不能是 `---`**（会被 Markdown 渲染器解析为 YAML 前言起始）
- ❌ 转场方式 / 跨场景一致性 / 尾帧截图（24s一次生成无需这些）

### 固定前提（每集不变，操作卡不再重复）

| 固定项 | 内容 |

## 五、📋 生成操作卡（强制第一项）

> ⚠️ AI 替用户做判断，直接告诉用户哪些需要准备、哪些不需要。**不要把判断甩回给用户。** v4.4起合并为单张操作卡，覆盖整集24s所有素材需求。

### 格式模板
```markdown
| 分类 | 检查项 | 你需要做什么 |
|------|--------|-------------|
| 🔴 必须 | 👤 角色参考图 | 上传标准角色图（固定前提） |
| 🟡 建议 | 🏙 背景参考图 | [场景名]：[判断：AI原生可画→"无需，提示词描述即可" / 场景特殊→"建议准备，理由：..."] |
| 🟡 建议 | 🖼 需参考图的道具 | [列出+理由] 或 **"全部道具AI原生可画，无需准备参考图"** |
| 🟢 无需 | ✍️ 仅需描述的道具 | [列出全片出现的通用日用品/家具/食物等] |
| ⚠️ 提醒 | 🏃 动作复杂度 | [普通日常→"无风险" / 快速奔跑/倒地/大幅度旋转→"提醒动作幅度大，生成可能降质"] |
| 🔴 必须 | 👤 角色变体 | [无变化→"沿用标准角色图" / 有变化→列出具体变化+是否需要变体参考图] |
| 🔴 必须 | 🎬 开场首帧 | [首帧画面描述] + [若为道具特写切入且该道具无参考图→⚠️"此道具无参考图，AI可能画不准，建议改为全景建立再推近"] |
| 🔴 必须 | 🎬 收尾 | [24s末画面描述：角色表情/姿势/道具状态/光线/情绪收束] |
```

> ⚠️ **v4.4起**：~~第一场景操作卡~~ 和 ~~第二场景操作卡~~ 合并为一张操作卡。无需再写转场方式、跨场景一致性、尾帧截图、场景间继续等。

### 道具分级规则 ⚠️

AI 必须根据道具的"AI认知难度"替用户做判断，分为三级：

| 级别 | 判断标准 | 用户操作 | 示例 |
|------|----------|----------|------|
| 🖼 需参考图 | AI 训练数据中罕见的特定造型物品 | 需准备参考图上传至「全能参考」 | 复古绿色小电风扇、断裂的浅绿色螺旋蚊香盘、复古黄铜台灯 |
| ✍️ 仅需描述 | 通用日用品/家具/食物，外观无歧义 | 无需准备，提示词描述即可 | 沙发、茶几、地毯、纸巾、饼干、羽毛、抱枕、遥控器、杯子 |
| ⚠️ 跨段道具 | 全片多次出现的关键道具 | 无需额外准备参考图，但需注意全片一致性 | 同一张茶几、同一个布丁碗，AI跨段可能有偏差属正常 |


### 角色变体判断规则 ⚠️

| 变化类型 | 是否需要变体参考图 | 示例 |
|----------|-------------------|------|
| 轻微表情/姿势变化 | ❌ 不需要 | 从开心→惊讶 |
| 发型变化（呆毛状态） | ⚠️ 视程度而定 | 呆毛微翘→不需要；呆毛炸成蒲公英→**建议准备** |
| 服装/配饰变化 | ⚠️ 视程度而定 | 戴了个发卡→不需要；换了整套衣服→**建议准备** |
| 身体覆盖物（面粉/泡沫） | 🖼 需要 | 浑身沾满面粉→需要变体参考图 |

### 铁律
- **AI 替用户判断，直接给出结论**，不得写"根据实际情况""待定""用户自行判断"
- 不得把判断甩回给用户
- 操作卡内容必须与内部构思的剧本一致
- 操作卡已覆盖全部素材需求，**不再单独输出素材需求清单**

### 🎬 双格式输出规范（Agent模式 + 连续叙事）⚠️

#### 格式A：Agent模式（按动作节奏灵活切段）

> ⚠️ **Agent 模式每段独立生成**，所以每段都要写 `主体严格参考@图片1`。

#### 格式B：连续叙事（一次性生成24s）

```markdown

```

#### 注意事项

| 规则 | 说明 |
|------|------|
| 两套格式输出顺序 | 先出格式A（Agent），再出格式B（连续叙事），用 `---` 分隔 |
| 收尾段 | 格式A 的末段即收尾段；格式B 中收尾融入叙事末尾 |
| @引用 | 两套格式共用一组 @引用（顶部声明一次） |
| 铁律 | 两套格式各自包含完整的角色铁律，方便直接复制 |

### 🎬 @引用语法（即梦素材引用）⚠️

即梦 Seedance 2.0「全能参考」模式通过 **`@素材名`** 在提示词正文中引用已上传素材。核心公式：

```
@素材X 作为[主体/首帧/参考对象]，参考@素材Y 的[动作/运镜/特效]...
```

**关键原则**：哪个素材管什么，就在提示词正文里写清楚。@引用**必须融入正文**，不能单独一行漂浮。

#### 主体锚定写法（我们的核心用法）

| 写法 | 说明 |
|------|------|
| `主体严格参考@图片1` | 角色外观锚定（每段必写，放在角色描述前） |
| `背景参考@图片3` | 场景风格锚定（可选，有背景参考图时写） |

#### 即梦官方 @语法速查

| 素材类型 | 编号范围 | 用途 |
|----------|----------|------|
| `@图片1` ~ `@图片9` | 最多 9 张 | 主体/首帧/尾帧/场景/服装/材质参考 |
| `@视频1` ~ `@视频3` | 最多 3 个（总时长≤15s） | 运镜/动作/转场/特效参考 |
| `@音频1` ~ `@音频3` | 最多 3 个（总时长≤15s） | 配乐/音效参考 |

> ⚠️ **v4.4起** 24s 整集一次生成：上传角色参考图（→ `@图片1`），背景参考图（→ `@图片3`）可选。无需尾帧。总文件上限 12 个。
> ⚠️ **Agent 模式每段独立生成**，每段提示词都必须写 `主体严格参考@图片1` 以锁定角色外观。

### 密度铁律 ⚠️

> ⚠️ 段长不固定，由动作节奏决定。字数按段长比例缩放。

| 段长 | 字数要求 | 示例场景 |
|------|----------|----------|
| 2s 段 | **120-180 汉字** | 单一表情/单次动作（如"啪一声静电炸开"） |
| 3s 段 | **180-280 汉字** | 标准叙事段（一个完整微动作+反应） |
| 4-5s 段 | **300-450 汉字** | 连续动作组（如"摩擦地毯蓄力→起身→冲过去"） |
| 6s+ 段 | **450-600 汉字** | 长镜头情绪推进（如"缓缓瘫软→被盖毯子→镜头拉远"） |
| 收尾段 | **200-300 汉字** | 全片收束，氛围余韵 |
| 全片总字符(含标点) | **≤2000 字**（超标则删冗余修饰，保留核心动作+表情+拟声词） |

### 每段必须包含六大要素（缺一不可）：
1. **场景氛围**：开头写环境/光线/气氛
2. **具体肢体动作**：哪个部位、怎么动、快慢、幅度
3. **面部表情变化**：眼睛/眉毛/嘴角/腮红/呆毛的具体变化
4. **拟声词**：咕嘎语（见第七节）
5. **道具/环境互动细节**
6. **光线/环境细节**

### 写作风格要求
- 像写叙事散文一样展开每个 3 秒
- 不缩写、不概括、不跳跃
- 每段以"日系萌圆暖柔handheld。"开头
- 每段以"natural motion，画面流畅不抖动，面部清晰不变形，人体结构正常，cinematic 4K quality, 电影质感，无模糊无闪烁。"结尾

## 七、咕嘎语言系统 + 音频铁律

### 咕嘎核心规则 ⚠️

> 🔑 **小企鹅的名字就是"咕嘎"，唯一发出的声音也是"咕嘎"。** "咕嘎"是所有情绪的唯一载体——兴奋、沮丧、疑问、撒娇、委屈，全部通过"咕嘎"的不同音调/节奏/长度区分。
> 🔑 **偶尔说单字**（如"不""要""吃""啊""嗯"），用于特定场景强化情绪，但**禁止完整句子/短语**。

### 🚫 绝对禁词

| 禁词 | 说明 |
|------|------|
| 嘎嘎 / Gaga | **严禁出现。** 任何独立于"咕嘎"的拟声词一律禁止 |
| 咕噜噜 / Gururu | 已由"咕嘎~~~"（拖长颤音）替代 |
| 其他非"咕嘎"拟声 | 不存在。咕嘎是唯一拟声词系统 |

### 拟声词表（全部为"咕嘎"变体，无其他）

| 拟声词 | 发声特征 | 情绪/用途 | 使用频率 |
|--------|---------|-----------|----------|
| 咕嘎 | 干脆混合声 | **默认叫声、万能回应、开心/惊讶/呼唤/确认** | ⭐⭐⭐ 最常用 |
| 咕嘎咕嘎 | 连续混合声 | 特别兴奋/手舞足蹈/强烈赞同 | ⭐⭐⭐ 常用 |
| 咕……嘎…… | 拖长渐弱 | 委屈/失落/无助/哭腔 | ⭐⭐ 情绪化 |
| 咕嘎？ | 上扬疑问 | 疑惑/好奇/试探 | ⭐⭐ 常用 |
| 咕嘎~~~ | 拖长颤音 | 满足/舒服/幸福（融化般） | ⭐⭐ 情绪化 |
| 咕嘎！咕嘎！ | 短促连续 | 着急/慌乱/不服气 | ⭐⭐ 常用 |

### 单字使用规则 ⚠️

| 适用场景 | 可用的单字 | 示例 |
|----------|-----------|------|
| 想吃东西/想要某物 | 吃、要、唔 | 伸出翅尖指蛋糕："吃。" |
| 拒绝/抗拒 | 不、哼 | 双翅抱胸扭头："不。" |
| 惊喜/顿悟 | 啊、哦 | 呆毛弹起："啊。" |
| 困倦/迷糊 | 困、嗯 | 揉眼打哈欠："困。" |
| 撒娇/回应 | 嗯、要 | 蹭大手："嗯~" |

> ⚠️ 单字出现频率：平均每集最多 2-3 次，其余全部是"咕嘎"系列拟声词。单字仅用于最需要点睛的情绪时刻。

### 音频铁律
- **全程仅使用"咕嘎"(Guga)拟声词**，偶尔出现单字（每集≤3次），**严禁独立"嘎嘎"(Gaga)或其他拟声词**
- 口型与语气、动作完全同步
- 人类大手通过动作传达意思，可配合画面字幕增强叙事

## 十、故事创作规则

1. **新主题**：不能与已用主题重复（参考运行时提供的已用主题列表）
2. **故事类型**：日常生活 + 笑点 + 反转
3. **结构**：根据随机选择的场景格式（§十一）：单长场景=24s连续叙事，双短场景=12s+12s双段叙事。Agent 模式按动作节奏自然切段（通常 4-7 段）。包含起承转合：建立场景→展开冲突→反转→收束余韵
4. **模式选择**：优先补 A/C 缺口（见 §三 智能均衡轮换规则），当前仅 A/C 模式可选
5. **每集至少要有一次"意外/反转"**——预期被打破才有笑点
6. **场景格式随机**：参照 §十一 铁律，50%概率选择单长/双短格式，禁止连续3集同一格式

## 十一、场景格式随机铁律 🔀 ⚠️

> ⚠️ **每次生成随机选择以下两种场景格式之一。50%/50% 概率。禁止连续 3 集同一种格式。**

### 格式一：单长场景（24s 连续叙事）— 占比 ~50%

当前 v4.4+ 标准格式。一个完整 24s 故事一气呵成，无场景切分。

| 参数 | 值 |
|------|-----|
| 时长 | 24s × 1 |
| 场景数 | 1（连续叙事） |
| 积分 | 200 |
| 特点 | 一个故事从头到尾，动作密度平滑，适合日常治愈 |

**输出结构**：一张操作卡 + 中文格式A/格式B（见 §四~§六）

### 格式二：双短场景（12s+12s 双段叙事）— 占比 ~50%

将 24s 拆为两个独立短场景，每个 ~12s，两段各自有起承转合。第二场景承接第一场景情绪/动作，形成转折或升级。

| 参数 | 值 |
|------|-----|
| 时长 | 12s × 2 = 24s |
| 场景数 | 2（独立双段） |
| 积分 | 200 |
| 特点 | 两个独立叙事节拍，节奏更快，适合有转折/反转的故事 |

**输出结构**：

```
1. 📋 生成操作卡                ← 一张操作卡，覆盖双场景全部素材
2. 🎯 即梦生成参数              ← 时长标注「12s × 2」
3. 中文提示词（双短场景）       ← 场景一 + 场景二，各自完整
```

> ⚠️ 双短场景：场景一建立情境→冲突/悬念；场景二承接→转折/反转→收束。两场景之间可以是时间跳跃、情绪转变、或意外反转。每场景内部仍用 Agent 模式按动作节奏切段。

> ⚠️ 双短场景**不输出格式B（连续叙事）**，仅输出 Agent 模式的【场景一】【场景二】分段。

| ⚠️ 操作卡 | 两种格式均只输出**一张**操作卡，覆盖全部时长素材需求 |
| 💰 积分 | 两种格式均为 200 积分/集（24s 总时长不变） |

## 十四、抖音标题生成规范

> 🎯 每集视频完成后，需生成符合抖音平台调性的标题。标题必须紧扣本集核心画面钩子+声音钩子+情绪钩子。

### 标题公式

```
[核心画面钩子] + [情绪张力] + [话题标签]
```

### 三大钩子（每条标题至少命中2个）

| 钩子类型 | 说明 | 示例 |
|----------|------|------|
| 🖼 画面钩子 | 本集最抓眼球的视觉瞬间 | "炸成蒲公英""被电弹起来""奶油糊满脸" |
| 🔊 声音钩子 | 咕嘎拟声词或标志性音效 | "咕嘎一声""啪！静电炸响" |
| 💓 情绪钩子 | 可爱/共鸣/反差/心疼 | "又气又好笑""冬天谁没被静电搞过" |

### 标题风格分类

| 风格 | 公式 | 适用场景 |
|------|------|----------|
| 反差向 | 本以为A，结果B | 反击失败/计划翻车/预期打破 |
| 共鸣向 | 谁还没经历过X？ | 生活日常类主题（静电、贪吃、赖床） |
| 剧情向 | X引发的Y | 完整因果链，引发好奇 |
| 治愈向 | 被X后的样子好乖 | 收尾暖心/融化瘫软/被毯子裹住 |
| 短打款 | 画面词+emoji+话题 | 需快速抓住注意力 |

### 标签规范

| 必选标签 | 可选标签（按剧情选） |
|----------|---------------------|
| `#咕嘎` `#萌系动画` | `#冬天静电` `#炸毛` `#可爱` `#治愈` `#动画短片` `#奶凶` |

- 总标签数 **3-5 个**
- `#咕嘎` 为每集必带品牌标签
- 禁用 `#嘎嘎` 标签

### 标题约束

| 规则 | 说明 |
|------|------|
| 长度 | 单条标题核心句 ≤30 字（不含标签） |
| Emoji | 1-3 个，不用潮语 emoji |
| 禁词 | 严禁标题中出现"嘎嘎"（连标签也不行） |
| 输出数量 | 每次给出 4-6 条备选，标注推荐款 |

### 示例（来自 脚本001_冬天静电）

```
推荐款：咕嘎一声，头发炸成了蒲公英⚡️ 冬天静电到底饶过谁
备选1：本以为能反击，结果又被电成毛球了⚡️🐧
备选2：冬天谁没被静电搞过心态？企鹅妹妹替我演出来了
备选3：一颗静电引发的恩怨情仇⚡️「咕嘎」
备选4：被电到炸毛的企鹅妹妹，最后一张毯子就乖了🥺
短打款：⚡️静电一碰，呆毛炸成避雷针 #咕嘎 #冬天静电
```
