# 🐧 战斗001：《枕头大战大魔王》

## 【场景一】对峙·准备阶段（12-15s）

**提示词：**
```
[画风] 日系萌系圆润画风，色彩温暖柔和，线条软糯Q弹。暖金色午后阳光洒满客厅，浅米色短绒地毯泛着奶油光泽。整体氛围 playful and bouncy（活泼弹跳），色彩倾向 C1 暖黄奶油质感。
[主体] 一只1:2头身比的Q版软萌企鹅妹妹，齐刘海碎发，黑色波波头蓬松柔软，头顶呆毛兴奋弹跳。脸颊自带粉扑扑红晕（加深型，草莓红），翠绿色圆眼瞪得溜圆，高光跳动，眼神充满斗志。人脸小嘴（粉色唇，人形动漫嘴巴），嘴角微翘露出得意笑容。毛茸茸黑白企鹅连体睡衣，纯白圆肚皮，鹅黄色蹼足。

[动作] 企鹅妹妹站在客厅中央，双翅抱胸，蹼足微微分开站稳，身体微微前倾，呆毛笔直竖立（警觉+斗志）。她面前三步远的地毯上，放着一个比她脑袋还大的卡通大枕头——这是她的"对手"。企鹅妹妹眯缝眼（得意笑），然后突然单蹼足跺地一下，发出"咕！"的一声（约1s慢镜头：跺足的瞬间，地毯绒毛微微弹起，腮红因用力加深）。接着她前倾踮脚，蹼足踮起，呆毛前指，摆出"准备进攻"的滑稽姿势。

[表情微动作] 瞪大眼（警觉+斗志）→ 眯缝眼（得意）→ 嘴角微翘（小计谋得逞）→ 蹼足跺地（催促/挑衅）。腮红加深型，草莓红。

[安全] 场景为客厅地毯，无高处/尖锐/电源危险。角色始终直立，翅膀不抓握，呆毛不勾取。
```

## 【场景二】交锋·高潮结果（12-15s）

**提示词：**
```
[画风] 延续场景一：暖金色午后阳光，暖黄奶油质感，活泼弹跳氛围。镜头从侧面低角度拍摄，展现动作爆发力。
[主体] 同一只Q版企鹅妹妹，情绪从斗志昂扬变为呆滞懵逼。

[动作] 企鹅妹妹深吸一口气，腮帮子鼓成两个圆球（鼓腮帮子=用力），然后——她使出了"终极奥义·飞扑撞击"！她双腿弯曲蓄力，整个圆滚滚身体像一颗粉色炮弹向前弹出（约1.5s慢镜头：腾空瞬间，呆毛因惯性向后拉直，蹼足在空中蹬踏，翅膀张开保持平衡，表情是奶凶的"咕咕咕——！"嘴型）。然而——她扑得太猛了，整个人直接撞进大枕头里，枕头被撞飞弹起，而她因为反作用力，一屁股坐在地毯上，身体微弹两下，呆毛完全软塌下来贴着头顶。

[结果] 枕头在空中翻转一圈，轻飘飘落在她头上，把她整个脑袋罩住。企鹅妹妹愣住，翅膀抬起摸了摸头上的枕头，呆毛从枕头边缘歪歪扭扭伸出来，微微弯成问号形状（极度困惑）。她缓缓摘下枕头，露出一张豆豆眼（瞳孔缩小成小黑点，高光消失）的懵逼脸。她歪了歪头，呆毛跟着歪向一侧，发出小声的"咕……？"（疑惑）。最后她抱着大枕头，就地一倒，慢慢瘫软在地上（从坐→侧躺→贴地），呆毛彻底塌下，表情变成眯缝眼（满足/放弃），仿佛在说"算了，躺着也挺舒服"。

[表情微动作] 鼓腮帮子（用力）→ 奶凶张嘴（冲刺瞬间）→ 豆豆眼（懵逼）→ 歪头（疑惑）→ 眯缝眼（满足摆烂）。腮红从加深型逐渐消退为淡粉。

[安全] 飞扑目标为柔软枕头，无碰撞硬物。摔倒方式为一屁股坐地+自然瘫软，无头部/颈椎伤害。翅膀始终不抓握，呆毛不勾取。
```

### 🔗 跨场景衔接判断
- **叙事连贯性**：✅ 场景一企鹅妹妹摆出战斗姿态挑衅枕头 → 场景二她发动攻击并扑空，以搞笑反转收尾。两段构成完整起承转合。
- **情绪弧线**：斗志昂扬（瞪眼跺脚）→ 全力冲刺（奶凶飞扑）→ 懵逼（豆豆眼）→ 摆烂躺平（眯缝眼满足）。情绪递进自然。
- **动作节奏**：场景一静态蓄力→场景二动态爆发+慢镜头定格+滑稽结果，符合萌系战斗"可爱>暴力"原则。
