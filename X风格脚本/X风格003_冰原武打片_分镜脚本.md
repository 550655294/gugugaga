🎬 观众席前排iPhone14手持POV。画面自然抖动，偶尔拍到企鹅观众鳍翅和灯笼入画。风格：whip pan + 冲击帧 + 慢动作。

【场景】黄昏冰原，极光流动。冰面被冰柱围成圆形场地，外围坐满企鹅观众举灯笼围观。冰面有自然裂纹和碎冰屑。

【角色A · 参考@图片1】企鹅妹妹：粉短发+呆毛，X面纹，粉连体服，白肚皮。黑鳍翅（圆钝弧形，无手指关节），蹼足。表情专注但圆胖体形自带萌感，短鳍翅摆任何架势都显滑稽。

【角色B · 参考@图片2】小星：金发蓝眼，白色连衣裙+蓝色饰边。动作轻盈流畅，面带微笑。

【分镜 · 5镜 · 15秒】

镜头1：起手式（0-2s）
广角低角度，对角纵深构图。企鹅在画面左前（中近景），小星在右后（中远景）——纵深拉开距离感。观众企鹅屏息围观。
企鹅沉下重心，蹼足在冰面上稳稳扎开，右鳍翅缓缓向前伸出——短翅伸到最远也只到身前一小截，呆毛竖直。*(喜剧：架势认真但短翅太短，观众席有企鹅"咕"地憋笑。)*
小星左脚后撤半步，身体微侧，右手在前左手在后——标准起手式，裙摆微扬。
两人静止对视一秒。极光在头顶流动。
📷🔊 广角低角度，轻微手持晃动。镜头从企鹅侧面缓推→两人中景→切小星反打。音效：风声 + 极光嗡鸣 + 冰面细微碎裂 + 观众憋笑。

镜头2：先手（2-5s）
企鹅先动——蹼足猛蹬冰面，圆胖身躯向前冲出，右鳍翅从身侧划出一道短弧劈向小星！*(喜剧：冲击很有力，但短翅挥出去的弧线太短——明明想劈到对方，鳍翅尖端离小星还差整整一个身位。观众"噗——"集体憋笑。企鹅翠绿大眼瞪圆：够不着！)*
小星轻盈后跳一步避开，裙摆飘起，脚尖点冰稳住。
企鹅第一击落空，惯性带着圆胖身体继续前冲——蹼足在冰上刹出一长道碎冰轨迹才停住。呆毛因急刹猛地甩向前方。
📷🔊 企鹅蹬冰时whip pan跟冲→挥翅瞬间切慢动作(60fps)：短翅在空中缓缓划过→差一截够不着的尴尬定格0.3s→小星后跳轻盈慢动作→企鹅刹停的碎冰飞溅。音效：蹬冰脆响 + 短翅挥空咻 + 观众"噗" + 小星点冰轻响 + 刹停冰面摩擦唰——。

镜头3：反击+格挡（5-8s）
小星借着后跳落地的弹性反弹上前——右脚蹬冰，身体侧转，右掌快速推向企鹅！动作行云流水。
企鹅瞳孔一缩——来不及闪，索性右鳍翅横在身前格挡。啪！小星的手掌拍在鳍翅上。
企鹅被推力震得向后滑了一小段——蹼足犁出两道冰痕。但她没倒，呆毛只是猛地一弹。*(喜剧：小星的推掌干净利落，企鹅的反应也很快——就是短翅挡完姿势像企鹅在抱一个看不见的大西瓜。)*
两人短暂分开，小星轻盈落地，企鹅稳住蹼足。各自重新调整站位——这次企鹅往前多走了一步，把距离缩短到自己短翅够得着的位置。眼神更认真了。
📷🔊 小星反击whip pan跟进→命中瞬间切冲击帧(0.2s黑白线稿，仅手掌与鳍翅接触点保留原色)→企鹅滑行慢动作→企鹅抱西瓜姿势定格0.3s→重新对峙中景。音效：蹬冰 + 推掌破空 + 命中啪！+ 冲击帧静音 + 滑行摩擦 + 观众"咕咕"。

镜头4：大招（8-12s）
企鹅深吸一口气——呆毛比之前竖得更直。她把重心压到最低，蹼足在冰面上碾了碾。
突然启动——这次不是直冲，而是侧向旋转！圆胖身体以蹼足为轴，整个身体带着右鳍翅旋转一圈——旋转时鳍翅尖端划出翠绿色光弧（不是光效爆发，而是高速旋转时冰晶在鳍翅尖端凝聚成的一圈淡淡荧光）。转完一圈后借着离心力，右鳍翅从下往上猛地撩起——方向直指小星！
小星选择硬接——双手交叉在身前，双臂并拢成防御。嘭！企鹅旋转撩翅撞上小星双臂——因企鹅体重的惯性太大，小星整个人被推得向后滑出，双脚在冰面犁出两道长痕。
同时企鹅自己也因为旋转后重心不稳——蹼足在冰上踉跄了两步，呆毛疯狂转圈→最终勉强用左鳍翅撑住冰面稳住。喘着粗气，圆肚皮大幅度起伏。
观众席企鹅集体"呜哇——！"后仰。
📷🔊 企鹅旋转时镜头绕着她快速弧移→旋转中的慢动作(120fps感)：圆胖身体缓缓转过→鳍翅尖端冰晶荧光拖出螺旋光尾→撩翅上挑瞬间切冲击帧(0.25s黑白，仅翠绿荧光保留)→命中硬接的碰撞切正常速度→两人各自滑退慢动作→观众后仰跟甩。音效：旋转带起的风声呜呜—— + 冰晶凝聚的细微叮叮 + 命中嘭！+ 冲击帧静音 + 两人滑行摩擦 + 观众惊呼。

镜头5：喜剧收尾（12-15s）
两人都停下来了，隔着碎冰喘气。
企鹅试着把撑在冰面上的左鳍翅抬起来——抬不动。低头一看：鳍翅插进冰面裂缝里卡住了。再抬——还是卡着。呆毛弹了弹。
小星甩了甩被震麻的双臂，看到企鹅的窘态，蓝眼瞪大→噗嗤笑出声。她指指企鹅卡住的鳍翅，又指指自己手臂上被企鹅胖身体撞出来的红印。
企鹅也跟着咯咯笑——呆毛重新弹起来——用力一拔→啵！拔出来了→但因为用力过猛向后翻了个跟头，四仰八叉躺冰上，呆毛弯成问号，短翅蹼足朝天扑腾。
小星笑得捂肚子蹲下来。观众企鹅集体爆笑："咕嘎嘎嘎嘎！！"有笑到拍冰面的，有后仰再翻倒的。
最终俯拍大远景：裂痕满地的冰面上，企鹅仰面扑腾，小星蹲在旁边笑，观众群笑翻。极光静静流动。
📷🔊 两人喘气中景→企鹅拔鳍翅特写(拔→拔不动→呆毛弹)→小星笑反打→企鹅拔出来翻跟头慢动作→四脚朝天扑腾近景→俯拍大远景渐弱。音效：喘气声 + 拔鳍翅嘎嘎 + 啵！+ 翻跟头嘎嘎嘎 + 嘭(萌系落地) + 扑腾啪嗒 + 小星笑声 + 观众爆笑回声。

【画质】4K萌系电影感，日系柔和色彩。shallow depth of field，volumetric lighting，极轻微film grain。色调：冰蓝冷白+极光粉紫+灯笼暖黄。冲击帧：黑白线稿+翠绿荧光保留原色。冰面：自然裂纹，非镜面。
