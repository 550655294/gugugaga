【场景】黄昏冰原，极光（翠绿+粉紫）在天空流动。冰面被冰柱围成圆形场地，外围坐满企鹅观众，举冰晶灯笼围观。冰面有使用痕迹：些许裂纹和碎冰屑。

【角色A · 参考@图片1】企鹅妹妹：粉短发+呆毛，X面纹，粉连体服，白肚皮。黑鳍翅（圆钝弧形，无手指关节），蹼足。柔和翠绿色冰晶光效环绕。表情专注但体形圆胖自带萌感。

【角色B · 参考@图片2】小星：金发蓝眼，白色连衣裙+蓝色饰边。柔和暖金色光效环绕。动作优雅，面带兴奋笑意。

【分镜 · 5镜 · 15秒】

镜头1：对峙（0-2s）
冰面两端，企鹅与小星相距五步正面相对。观众企鹅屏息围观。
企鹅沉下重心，右鳍翅一收——翠绿光效从全身亮起，脚下冰面震出裂纹，呆毛被气流吹直。
小星双手一抬——暖金光效从脚底升起，连衣裙和金发向上飘飞。
两股光效在场地中央相抵，翠绿与暖金的分界线处空气微微波动，冰屑在两光之间旋转。观众席发出"呜哇——"的惊叹。
📷🔊 广角正面，手持轻晃。两人之间快速平移切换→企鹅特写（翠眼发光）→小星特写（蓝眼发光）→中景双人。音效：两股低频嗡声交织攀升 + 冰面嗞咔碎裂 + 观众惊呼。

镜头2：先手+闪避（2-5s）
企鹅先出手——蹼足蹬冰，圆胖身体前冲，右鳍翅猛挥！一道翠绿月牙光刃贴着冰面飞出，沿途扬起碎冰。*(喜剧：挥招同时蹼足在碎冰上打了个滑，踉跄了一下，呆毛甩向一边，观众"噗——"憋笑。企鹅表情从帅气变尴尬——但光刃已飞出。)*
小星侧身→蹬冰横移闪避，暖金残影拖出弧线。光刃擦着她裙边飞过，在身后冰面扬起大片碎晶花。同时她已借着惯性转身蓄好反击。
📷🔊 whip pan追光刃→企鹅打滑时镜头一抖→小星闪避切慢动作(60fps)：身体倾斜→残影滑动→光刃擦过裙边→碎晶花绽开。音效：蹬冰脆响 + 光刃嗖—— + 打滑叽溜 + 观众憋笑 + 碎晶叮—— + 慢动作降调。

镜头3：反击+格挡（5-8s）
小星双手一推——三道暖金光箭并排射向企鹅。企鹅右鳍翅横挥，翠绿光盾在身前展开。*(喜剧：光盾太大遮住半张脸，只露发光大眼和震颤呆毛，像躲墙后的小动物。观众"咕咕咕"笑。)*
三箭接连命中光盾同一位置——嘭嘭嘭！企鹅被推得向后滑行，蹼足犁出两道冰沟，但始终没倒。最后一箭弹向天空，散成暖金光花。光盾碎裂，化作翠绿碎晶洒落。
📷🔊 whip pan追三箭→光盾遮脸定格0.5s→命中瞬间切冲击帧(0.2s黑白线稿，仅撞击点保留金绿双色)→企鹅滑行慢动作→光盾碎晶飘落。音效：嗡 + 咻咻咻三连音 + 嘭嘭嘭命中 + 冲击帧静音 + 冰面摩擦唰—— + 碎晶叮叮叮。

镜头4：全力一击（8-12s）
企鹅稳住，将翠绿光全部汇聚到鳍翅尖——光球急速膨胀旋转，碎冰绕她旋转成环带。小星同时将暖金光汇聚双掌——光球同样膨胀，金发狂舞。*(喜剧：企鹅的光球大到和肚子一样大，短翅托着巨球抖个不停，像举巨型珍珠奶茶。观众后仰："嘎嘎嘎——！")*
两人同时推出光球。翠绿拖螺旋尾迹，暖金拖六条光尾，在冰面正中央空中相遇。
交汇处寂静绽放为巨大冰晶光花——七彩花瓣层层展开。冰面从中心向外辐射出大片裂纹，观众席企鹅集体后仰翻倒，灯笼乱滚。
两人被气浪推后：企鹅滑出很远，鳍翅插入冰面刹停；小星踉跄跪地，发乱帽歪。
📷🔊 光球膨胀特写→喜剧穿插(企鹅举巨球)→推出时猛然后拉→相遇切120fps超慢动作：光花逐层绽放+四角度切换→绽放瞬间冲击帧(0.3s黑白，仅光花七彩)→地面裂纹+观众翻倒跟甩→两人滑倒慢动作→俯拍裂纹大远景。音效：蓄力嗡声双轨攀升 + 光花绽放3秒静音留白 + 低沉嗡—— + 地面碎裂咚—— + 观众翻倒乱响 + 两人滑行摩擦声。

镜头5：喜剧反转（12-15s）
光花消散，冰晶粉末飘落。极光仍在流动。
企鹅拔鳍翅——卡在冰缝里拔不动。再拔→圆肚皮一挺→还是拔不动。呆毛尴尬弹动。
小星试图站起→右脚一滑→坐回地上→再试→再滑。两人隔着满地碎冰对视一秒。
企鹅："咕嘎……"（虚弱憋笑）
小星噗嗤笑出来，指指企鹅卡住的鳍翅，又指指自己掉了一只鞋的狼狈模样。
企鹅咯咯笑→用力→啵！拔出来→因惯性向后翻了个跟头→四仰八叉躺冰上，呆毛弯成问号，短翅蹼足朝天扑腾。
小星捂肚子笑出眼泪。观众企鹅集体爆笑——"咕嘎嘎嘎嘎！！"有拍冰面的，有笑翻再倒的。
最终俯拍大远景：裂痕遍地的冰面上，企鹅仰面扑腾，小星笑坐，观众群笑翻。极光静静流动。
📷🔊 光花慢速消散→拔鳍翅卡住特写→小星滑倒→对视静默→咕嘎→噗嗤→拔出来翻跟头慢动作→四脚朝天扑腾→俯拍大远景渐弱。音效：嗡渐弱 + 拔鳍翅嘎嘎 + 滑倒呲溜 + 静默 + 咕嘎 + 笑声 + 啵！+ 翻跟头嘎嘎嘎 + 嘭(萌系落地) + 扑腾啪嗒 + 集体爆笑回声。

【画质】4K萌系电影感，日系柔和色彩。shallow depth of field，volumetric lighting，极轻微film grain。色调：冰蓝冷白基底+翠绿光+暖金光+极光粉紫。冲击帧：黑白线稿+光效保留原色。冰面：有自然裂纹和碎屑，非镜面感。
