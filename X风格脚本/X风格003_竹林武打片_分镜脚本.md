【场景】黄昏竹林空地，斜阳透过层层竹叶洒下斑驳光影（暖金色+翠绿）。空地四周自然环绕高大青竹，外围坐满企鹅观众，有的趴在倒下的竹干上，有的倚着竹丛围观。地面是松软泥土+散落的竹叶，踩上去带轻微沙沙声。

【角色A · 参考@图片1】企鹅妹妹：粉短发+呆毛，X面纹，粉连体服，白肚皮。黑鳍翅（圆钝弧形，无手指关节），蹼足。表情专注但圆胖体形自带萌感，短鳍翅摆任何架势都显滑稽。

【角色B · 参考@图片2】小星：金发蓝眼，白色连衣裙+蓝色饰边。动作轻盈流畅，面带微笑。

【分镜 · 5镜 · 15秒】

镜头1：起手式（0-2s）
广角低角度，对角纵深构图。企鹅在画面左前（中近景），小星在右后（中远景）——纵深拉开距离感。观众企鹅屏息围观，竹林间微风使竹叶轻摇。
企鹅沉下重心，蹼足在泥土上稳稳扎开，右鳍翅缓缓向前伸出——短翅伸到最远也只到身前一小截，呆毛竖直。*(喜剧：架势认真但短翅太短，观众席有企鹅"咕"地憋笑。)*
小星左脚后撤半步，身体微侧，右手在前左手在后——标准起手式，裙摆微扬。
两人静止对视一秒。竹影在两人身上缓缓移动，光斑忽明忽暗。
📷🔊 广角低角度，轻微手持晃动。镜头从企鹅侧面缓推→两人中景→切小星反打。音效：竹叶沙沙 + 风声穿过竹林 + 泥土细微沙响 + 观众憋笑。

镜头2：先手（2-5s）
企鹅先动——蹼足猛蹬地面，圆胖身躯向前冲出，右鳍翅从身侧划出一道短弧劈向小星！*(喜剧：冲击很有力，但短翅挥出去的弧线太短——明明想劈到对方，鳍翅尖端离小星还差整整一个身位。观众"噗——"集体憋笑。企鹅翠绿大眼瞪圆：够不着！)*
小星轻盈后跳一步避开，裙摆飘起，脚尖点地稳住。身后竹叶被风带起盘旋。
企鹅第一击落空，惯性带着圆胖身体继续前冲——蹼足在泥地上刹出一长道浅沟和飞起的竹叶才停住。呆毛因急刹猛地甩向前方。
📷🔊 企鹅蹬地时whip pan跟冲→挥翅瞬间切慢动作(60fps)：短翅在空中缓缓划过→差一截够不着的尴尬定格0.3s→小星后跳轻盈慢动作→企鹅刹停时竹叶飞溅。音效：蹬地闷响 + 短翅挥空咻 + 观众"噗" + 小星点地轻响 + 刹停沙沙——。

镜头3：反击+格挡（5-8s）
小星借着后跳落地的弹性反弹上前——右脚蹬地，身体侧转，右掌快速推向企鹅！动作行云流水。
企鹅瞳孔一缩——来不及闪，索性右鳍翅横在身前格挡。啪！小星的手掌拍在鳍翅上。
企鹅被推力震得向后滑了一小段——蹼足犁出两道浅痕，扬起碎竹叶。但她没倒，呆毛只是猛地一弹。*(喜剧：小星的推掌干净利落，企鹅的反应也很快——就是短翅挡完姿势像企鹅在抱一个看不见的大西瓜。)*
两人短暂分开，小星轻盈落地，企鹅稳住蹼足。各自重新调整站位——这次企鹅往前多走了一步，把距离缩短到自己短翅够得着的位置。眼神更认真了。一阵风过，竹叶纷飞从两人之间飘落。
📷🔊 小星反击whip pan跟进→命中瞬间切冲击帧(0.2s黑白线稿，仅手掌与鳍翅接触点保留原色)→企鹅滑行慢动作→企鹅抱西瓜姿势定格0.3s→重新对峙中景+竹叶飘落。音效：蹬地 + 推掌破空 + 命中啪！+ 冲击帧静音 + 滑行沙沙 + 竹叶飘落簌簌 + 观众"咕咕"。

镜头4：大招——旋转撩翅（8-12s）
企鹅眼神一凛，深吸一口气——蹼足蹬地，圆胖身体逆时针高速旋转！翠绿残影环绕周身，卷起地面竹叶形成小旋风。*(喜剧：旋转时呆毛像直升机螺旋桨一样水平旋转，观众企鹅集体抬头看呆毛，发出"哇——"的惊叹。)*
转了三圈加速完毕——企鹅借助旋转惯性右鳍翅横扫而出！这次她算好了距离——短翅刚好够到小星所在位置！
小星双臂交叉格挡——咚！碰撞激起一圈气浪，周围竹叶被吹得向外环散开！
小星被推得向后滑退两步，裙摆和头发被气浪吹向后方——但稳稳停住。抬头看企鹅，眼里满是"不错嘛"的欣赏。
企鹅旋转后踉踉跄跄停下，蹼足八字站稳，呆毛歪向一边，翠绿大眼转着圈圈——晕了。*(喜剧：大招放完了，自己也转晕了。观众席笑成一片。)*
📷🔊 企鹅旋转whip pan环绕→呆毛直升机特写0.3s→旋转加速慢动作→横扫命中切冲击帧(0.2s黑白线稿，仅鳍翅与手臂接触点保留原色)→小星滑退慢动作(60fps)+竹叶环散→企鹅晕眩特写：眼睛转圈0.5s。音效：旋转嗡—— + 呆毛螺旋咻咻咻 + 横扫破空呜—— + 命中咚！+ 冲击帧静音 + 气浪轰 + 小星滑退沙—— + 企鹅晕眩叽哩叽哩 + 观众大笑。

镜头5：喜剧收尾（12-15s）
企鹅晕乎乎地原地晃了两圈——蹼足终于站稳。抬头看向小星，表情从恍惚变回认真——又想继续打。
小星却笑着摇了摇头，伸手指指企鹅身后。企鹅回头——身后地面被她的蹼足刹出一道深沟+一堆散乱竹叶，像被小型翻土机刨过一样。*(喜剧：竹林空地被她整得像农忙现场。)*

企鹅呆毛啪地软下来，翠绿大眼变成半圆无奈表情。小星走上前，伸手帮企鹅把歪掉的呆毛轻轻扶正。两人面对面，企鹅不好意思地用鳍翅挠了挠后脑勺。
